# VinePalma Leaf 架构设计

## 概述

VinePalma Leaf 采用 Tauri v2 架构，结合 Rust 后端和 React 前端，提供高性能、跨平台的电子书阅读体验。

## 核心模块

### 1. 格式解析引擎

负责解析各种电子书格式，提供统一的文档接口。

- **EPUB 解析**: 基于 zip + OPF 规范
- **PDF 渲染**: 使用 Google PDFium 引擎
- **TXT/Markdown**: 纯文本解析与转换
- **MOBI/AZW3**: 使用 libmobi 库

### 2. 排版引擎

负责文档内容的排版和渲染。

- **分页算法**: 根据屏幕尺寸和设置进行分页
- **字体回退**: 支持多种字体和字符集
- **CSS 子集**: 支持自定义样式

### 3. 同步引擎

负责多设备间的数据同步。

- **局域网同步**: mDNS 设备发现 + TCP 数据传输
- **蓝牙同步**: BLE 轻量级同步
- **WebDAV**: 云存储同步
- **冲突合并**: 三向合并算法

### 4. 数据库层

负责本地数据的持久化存储。

- **SQLite**: 轻量级嵌入式数据库
- **FTS5**: 全文搜索索引
- **数据迁移**: 版本化数据库结构

## 数据流

1. **导入书籍**: 文件系统 → 格式解析 → 数据库存储
2. **阅读书籍**: 数据库 → 排版引擎 → 前端渲染
3. **同步数据**: 本地数据库 → 序列化 → 网络传输 → 反序列化 → 远程数据库

## 安全考虑

- **沙箱环境**: 前端运行在 WebView 沙箱中
- **权限控制**: Tauri v2 能力系统控制应用权限
- **数据加密**: 可选的端到端加密同步
- **文件验证**: 书籍文件完整性校验
